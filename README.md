# 巡店云

面向巴布豆商丘区域 10 家门店的「总经理 + 督导 + 门店」三端巡店与经营分析 MVP。功能依据“巴布豆巡店·三端小程序”和门店数据后台整理。

## 运行

无需安装依赖，直接运行：

```powershell
node server.js
```

浏览器打开 `http://127.0.0.1:4173`。

也可以直接双击 `index.html` 预览；安装为 PWA 时请使用本地服务器。

## 已实现

- 总经理端：11月24日销售与毛利、门店排行、巡店质量、整改总览，支持手机查看与审批
- 门店设置：营业状态、营业时间、联系人和门店基础资料
- 门店设置支持新增、编辑和删除门店，页面不含任务下发入口
- 人员账号：总经理、督导、门店人员三类账号；门店人员统一绑定门店，不区分店长和导购
- 任务体系：总经理可下发督导巡店任务、督导其他任务，也可直接下发门店运营任务
- 任务说明支持上传最多 3 张参考图片，执行人员可直接查看
- 任务闭环：执行人提交完成反馈和照片，总经理审核通过或驳回补做
- 门店完成反馈支持上传最多 3 张完成图片
- 督导端：现场主动发起巡店、25 项运营标准、逐项评分，支持手机操作
- 督导路线：督导自主选择今日巡店门店并调整到访顺序，下一站按路线自动确定
- 不符合项：逐项强制拍照、填写问题反馈，提交后自动生成整改任务
- 督导巡检照片仅支持调用实时摄像头，不能从相册上传
- 督导现场照片自动叠加门店、督导、时间和检查项目水印
- 大项留档：卫生 2 张、商品 2 张、人员 1 张、氛围 1 张、安全 2 张
- 大项反馈：卫生、商品、人员、氛围、安全均需填写整体反馈
- AI 自检：自动检查图片格式、尺寸、亮度与清晰度，模糊、过暗或过曝时提示重拍
- 自动更新：在线用户定时检查版本，发布新版本后自动刷新；重新打开应用时也会获取最新版
- 当前暂不提供总经理向督导派发巡店任务
- 门店端：门店得分、待整改事项、整改提交与巡检记录
- 问题闭环：待处理、整改中、待复核、已关闭
- 账号审批、门店档案、巡检标准、经营报表和 CSV 导出
- 响应式布局、本地持久化、离线和 PWA 安装支持

门店清单、销售与毛利来自当前商丘 10 店数据；个人备注和巡店操作保存在浏览器 `localStorage`，不会上传到任何服务器。右上角可在三种角色间切换。
